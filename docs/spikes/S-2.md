## Protocol

1. Install Google's official **OboeTester** app (`Tap-to-Tone Latency` / `Round Trip Latency` test). Configure the output
   stream in Exclusive + LowLatency mode, logging whether AAudio or OpenSL ES fallback is used.
2. Measure touch-to-tone latency using a direct audio loopback setup (piezo/contact mic on screen or OboeTester's validated
   internal loopback); perform 30 taps.
3. Report median, p90, `framesPerBurst`, granted buffer size, sharing mode, and whether the low-latency performance mode was honoured.

**Fallback if no-go:** larger sample pre-roll in RAM, `setBufferSizeInFrames(burst)` after warm-up, and if still above
60 ms on mid-range, ship Voice-only for Milestone 1 and keep Piano behind the gate.
